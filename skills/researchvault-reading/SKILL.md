# ResearchVault 中文资料阅读

## 03原始资料保护规则（优先适用）

- `03原始资料/`及其全部子目录默认只读。未经用户明确允许，不得在其中新增、编辑、覆盖、重命名、移动或删除文件、目录；不得改写正文、属性、链接、图片或附件。
- “阅读”“精读”“总结”“生成笔记”等请求只授权读取原始资料并在`02阅读笔记/`生成或更新对应笔记，不视为对`03原始资料/`的修改授权；包括自动全文归档、OCR回写、格式修复和索引更新在内，也不得据此写入该目录。
- 如需转换、OCR或其他中间处理，使用该目录之外的临时工作区；原件保持不变。已有原始资料可只读复用，缺少归档不妨碍基于可访问原文完成阅读笔记。
- 只有用户明确授权修改`03原始资料/`中的指定范围时，才执行对应操作；已有明确授权无需重复确认，不得将局部授权扩大为整库修改。如确实需要额外写入，应说明具体文件与操作并取得允许后再执行。


先读取活动Vault的AGENTS.md与对应模板。Zotero管理文献原件和书目，03原始资料接收用户保存的各类材料，02阅读笔记保存逐资料理解，01知识图谱保存经授权的跨资料综合。

## 路径规则

- Zotero论文：`02阅读笔记/论文/<集合>/<原始标题>.md`；需要全文归档时使用`03原始资料/论文/<集合>/<zotero_key>.md`。
- 读取`03原始资料/<类别>/<主题子路径>/<资料>`，生成`02阅读笔记/<类别>/<相同主题子路径>/<中文标题>.md`。类别初始为网页、论文、笔记、收件箱、数据、日记、书籍、附件；用户新建主题目录时照原相对目录对应，不另猜类别。
- 原始文件保持原位、原名、原内容；不因阅读自动移动、覆盖或删除。辅助转换文件与原材料明确区分。
- 普通资料使用`模板/资料阅读模板.md`，论文使用`模板/论文精读模板.md`。已有同源笔记原位补全，保护人工“我的判断”；不因标题不同重复建笔记。

## 属性与身份

属性只保留并按模板顺序使用18项中文名称：类型、标题、作者、期刊标签、标签、年份、创建日期、主题、研究对象、数据来源、研究方法、核心变量、主要发现、研究关联、原文链接、文献集合、原始资料路径、核验日期。

类型值分别为论文精读、资料阅读。论文笔记的标题属性、一级标题和基本信息保留论文原始标题：英文论文用英文原题，中文论文用中文原题，不再强制翻译。新论文笔记文件名默认使用原题（仅清理文件名非法字符）；已有笔记原路径保留，避免改写03原始资料中的反向链接。其他资料的目录对应关系不变，原始资料仍默认只读。 论文原题、DOI、Zotero父条目键、附件键、库身份、笔记路径及完成状态保存在`<!-- researchvault-metadata {...} -->`隐藏元数据中，不重新添加到可见属性。原文链接保持真实URI或来源地址。缺失作者/年份不猜，缺失列表保留空列表。

工具仓库为活动Vault的`.research-tools/Zotero-Analytical-Workflow-Skills`。`tools/vault_schema.py`定义中英文兼容字段及隐藏身份读取；`tools/create_note_draft.py`仅建元数据草稿，论文正式完成必须经全文核验；`tools/create_material_note.py`按源文件相对路径准备普通资料草稿。论文直接使用Zotero原题，不要求提供中文译题。

期刊标签从Zotero publicationTitle、期刊相关Tags和Extra提取，使用`tools/journal_metadata.py`。不把主题标签/TLDR写为期刊标签，不声称无年度信息的IF或分区为最新。

## 阅读与交付

“精读”“阅读并生成笔记”授权指定材料的笔记；03原始资料内的配套归档仍需明确授权；只问某问题默认只读。先查已有笔记，再读取相应源文件，按实际文件能力提取正文、表格、公式和图像。记录真实证据位置，区分作者结论与阅读者判断；无法获取全文则保持draft并说明缺证，不伪造引文、页码或结果。

完成时校验18项中文属性、源文件存在、对应目录、原题与稳定身份、引用、链接和人工内容保护，报告实际笔记路径。不要自行批量处理无关材料或写入知识图谱。

论文采用精简模板：方法分析按任务与数据、同步与处理、核心方法、结果验证、优势与局限、对我的借鉴六项填写，不设置公式推导栏；研究结论按“主要发现 n + 原文引用 n”配对并注明核验页码。
