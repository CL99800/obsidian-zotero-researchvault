# ResearchVault — 中文资料工作区规则

## 目录与对应关系

- `01知识图谱/`：经用户授权的跨资料概念、方法、关系与综合；不能把单篇摘要当成知识图谱综合。
- `02阅读笔记/`：各类资料的中文阅读笔记。
- `03原始资料/`：用户保存的原始材料与明确标识的可再生全文归档。
- 后两层均设网页、论文、笔记、收件箱、数据、日记、书籍、附件八类；允许用户在其中继续建立主题子目录。
- Zotero精读固定写到`02阅读笔记/论文/<集合>/<原始标题>.md`，对应全文归档在`03原始资料/论文/<集合>/<zotero_key>.md`。原始PDF仍由Zotero管理，不移动或改写。
- 阅读`03原始资料/<类别>/<主题子路径>/<文件>`时，笔记保存到`02阅读笔记/<类别>/<同一主题子路径>/<中文标题>.md`；用户新增任意主题目录也按相对路径对应，不另猜位置。

## 03原始资料保护规则（优先适用）

- `03原始资料/`及其全部子目录默认只读。未经用户明确允许，不得在其中新增、编辑、覆盖、重命名、移动或删除文件、目录；不得改写正文、属性、链接、图片或附件。
- “阅读”“精读”“总结”“生成笔记”等请求只授权读取原始资料并在`02阅读笔记/`生成或更新对应笔记，不视为对`03原始资料/`的修改授权；包括自动全文归档、OCR回写、格式修复和索引更新在内，也不得据此写入该目录。
- 如需转换、OCR或其他中间处理，使用该目录之外的临时工作区；原件保持不变。已有原始资料可只读复用，缺少归档不妨碍基于可访问原文完成阅读笔记。
- 只有用户明确授权修改`03原始资料/`中的指定范围时，才执行对应操作；已有明确授权无需重复确认，不得将局部授权扩大为整库修改。如确实需要额外写入，应说明具体文件与操作并取得允许后再执行。

## 阅读与授权

- 普通问答先检索阅读笔记，证据不足再定向读取原始资料、Zotero全文或PDF；只问问题默认只读。
- “精读论文”“阅读资料并生成笔记”等明确请求授权处理指定材料、写入对应笔记；写入03原始资料须另有明确授权，无需再次询问存放位置。不得自动批量处理其他材料或改写01知识图谱。
- 先读当前`模板/论文精读模板.md`或`模板/资料阅读模板.md`。已有同一来源笔记时原位补全；保护用户人工“我的判断”，不制造重复笔记。
- 论文笔记的标题属性、一级标题和基本信息保留论文原始标题：英文论文用英文原题，中文论文用中文原题，不再强制翻译。新论文笔记文件名默认使用原题（仅清理文件名非法字符）；已有笔记原路径保留，避免改写03原始资料中的反向链接。其他资料的目录对应关系不变，原始资料仍默认只读。
- 18项可见属性只使用中文：类型、标题、作者、期刊标签、标签、年份、创建日期、主题、研究对象、数据来源、研究方法、核心变量、主要发现、研究关联、原文链接、文献集合、原始资料路径、核验日期。未读完资料不编造已完成状态、结果或引文。
- Zotero条目键、附件键、库身份、DOI、原题及处理状态保存在笔记的`researchvault-metadata`隐藏JSON注释中，不占用可见属性；始终保留稳定身份。`tools/vault_schema.py`兼容读取旧英文字段及新中文属性。
- “期刊标签”使用Zotero publicationTitle、期刊相关Tags及Extra；缺失分区、IF或年份不猜，不把库中快照说成最新排名。

## 工具与核验

工作流工具在`.research-tools/Zotero-Analytical-Workflow-Skills`。论文使用Fetcher、Fulltext Archiver和Analytical Writer；普通资料与路径规则见`.agents/skills/researchvault-reading/SKILL.md`。

- `tools/retrieval_gateway.py`：先笔记后原文的只读检索，支持中文属性和隐藏Zotero身份。
- `tools/create_note_draft.py`：创建论文元数据草稿，不能代替精读。
- `tools/create_material_note.py`：按原始资料相对主题目录准备资料笔记草稿。
- `tools/validate_research_vault_literature_links.py`：检查论文双向链接及普通资料来源。

原始材料、PDF、批注和Zotero数据库保持不变，禁止写zotero.sqlite。精确引文、公式、表格和页码回到实际来源核验；不伪造材料、统计或出处。引用支持到什么范围就表述到什么范围。新建后检查中文属性、路径、稳定身份、来源链接与原文证据，报告真实完成事项及限制。
